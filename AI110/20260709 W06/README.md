# Week 6 — Data, Bias, and Evaluation

**AI110 · Module 3 · Lesson 2** · 2026-07-09

## 课堂笔记

- **准确率会骗人**：准确率 99% 的欺诈检测可能毫无用处（全部预测"不是欺诈"）。
- **混淆矩阵**：TP / FP / FN / TN。
- **Precision vs Recall**（课件例子：1000 条评论，100 条有害 → P = 60/80 = 75%，R = 60/100 = 60%，Acc = 94%）。
- **选指标 = 选择容忍哪种错误。**
- **Bias 是系统属性**：Amazon 简历 AI（歧视女性）、医疗算法（按花费而不是需求打分，把黑人病人判为"更健康"）。
- **应对**：Fix / Constrain / Document。
- **Model Card 的四个部分。**
