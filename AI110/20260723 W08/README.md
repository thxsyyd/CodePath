## 课堂笔记

**一句话：** "AI 帮你干活，锅还是你背。"（Accountability doesn't transfer.）AI 是队友，不是老板。

- **金句**："If the AI introduces a bug, you introduced a bug."
- **案例**：Deloitte 44 万澳元报告（引用了编造的论文，退钱）、三星源代码泄露（2023）、Klarna 重新雇回客服（2024）。
- **AI 的四种失败模式**：missing context / ambiguous instructions / overgeneralization（麦当劳 260 块鸡块）/ false confidence（律师引用 6 个编造的案例）。"Sounding right is not being right."
- **三种 Guardrail**：input / output / **execution**（最关键）。
- **Claude Code Hooks**：exit 0 放行 / exit 2 拦截。"The model can't talk its way past an exit code."
- **Over-guarding 的代价**："How safe is too safe?" 考验的是判断力。
