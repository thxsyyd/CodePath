# Week 2 — Debugging and Refactoring with AI Tools

**AI110 · Module 1 · Lesson 2** · 2026-06-11

本周没有 Lab，也没有 Project。

## 课堂笔记

- **"盲目粘贴"的危险**：别把完整错误日志直接粘给 AI（可能泄露 API key，AI 也可能用删掉核心逻辑的方式"修复"）。正确做法：先自己读错误类型，清理敏感数据，再针对性提问。
- **三步调试法 Triage → Prompt → Verify**：用 `grade_parser.py` 演示——先自己分诊看懂错误，只问相关部分，修完跑测试（空列表又触发 `ZeroDivisionError`，说明 AI 没想到边界情况）。
- **测试 = 证明，不是"跑一次没崩"**：用 `assert` 和 `pytest` 锁定行为。
- **重构三步**：先 commit → 让 AI 重构 → 跑测试验证（全绿 = 结构变了、行为不变）。
- **AI 常犯错**：语法正确 ≠ 逻辑正确（用 `!=` 代替 `<` 导致无限循环）。"AI 生成语法完美的废话，你是逻辑过滤器。"
