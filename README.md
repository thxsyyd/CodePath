# CodePath

Coursework, labs, and projects from my CodePath courses.

| Course | Term | Highlights |
|---|---|---|
| [AI110 — Foundations of AI Engineering](AI110/) | Summer 2026 | AI-assisted development, ML basics, RAG, agents and guardrails. Final project: [DocuBot Pro](AI110/20260730%20W09/Project/docubot-pro/), a RAG assistant with confidence scoring, a refusal guardrail, trace logging and an offline evaluation harness. Each course is organized by week, matching the class schedule (`YYYYMMDD Wxx/`, with `Lab/` and `Project/` inside).
Projects keep their full commit history, starting from the course starter code.

## Starting a new project

Course projects are created directly in this repo instead of being forked.
See [tools/README.md](tools/) for how to import a starter repo with its history.
